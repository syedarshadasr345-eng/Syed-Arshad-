## 📦 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/syedarshadasr345-eng/Syed-Arshad-.git
   cd Syed-Arshad-
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
